## About the Project

The Panther Shuttle App Website is the public documentation site for the Panther Shuttle App senior design project. The website organizes project deliverables, milestone presentations, progress evaluations, design documents, testing materials, user/developer documentation, and demo resources in one central location.

The main Panther Shuttle App is an Android mobile application designed around three user roles:

- **Student** – view shuttle schedules, live map updates, favorite stops, notifications, and next stop information
- **Driver** – share live shuttle location, view upcoming stops, estimate student demand, and send notifications
- **Manager** – manage shuttle stops, edit schedules, and maintain route information

This website supports the project by presenting the development process, documentation, and semester-by-semester progress.

---

## Website Purpose

This site was created to:

- Present senior design project deliverables
- Organize first and second semester milestones
- Provide quick access to presentations, reports, and evaluations
- Showcase the development progress of the Panther Shuttle App
- Serve as a public project page for the final senior design submission

---

## Main App Features

The Panther Shuttle App includes:

- Live shuttle map tracking
- Daily shuttle schedule viewing
- Favorite stop selection
- Student notifications
- Driver-to-student announcements
- Manager schedule editing
- Stop marker management
- Firebase-based cloud data storage
- Google Maps integration
